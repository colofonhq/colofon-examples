# Approved-builder Fulcio identities for colofon-examples releases.
#
# Fulcio-issued SAN URIs pin the workflow file + the ref it ran
# from. For tag-triggered workflows the ref is `refs/tags/<tag>`;
# for branch-triggered workflows it's `refs/heads/<branch>`. Each
# distinct (workflow, ref) pair is a distinct identity in the
# approved-builder Merkle set baked into every Colofon proof.
#
# The first line is the signer identity of the release this commit
# targets; additional lines form the rest of the approved-builder
# Merkle set.
#
# KNOWN LIMITATION: every new tag requires an entry in this file
# because the circuit's approved-builder check is by exact identity
# hash. A future circuit revision could hash just the workflow
# path (without the ref) so any tag under the same workflow
# verifies without this file being updated. Tracking as a planned
# hardening step.
#
# Lines starting with `#` and blank lines are ignored.
